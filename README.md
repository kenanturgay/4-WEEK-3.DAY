# User List Project

This project shows a list of users.  
You can delete users.  
If all users are deleted, you see a reload button.  
Click the reload button to get all users again.  
The reload button works only one time in one session.

## How to use

1. Open the project in your browser.
2. See the user cards.
3. Click "Delete" to remove a user.
4. If all users are deleted, click "Reload" to bring them back.

## Technologies

- JavaScript
- jQuery
